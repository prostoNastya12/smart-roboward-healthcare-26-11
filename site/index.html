Smart RoboWard

IFOHRA Challenge 9: secure robotics in clinical environments · Healthcare Hackathon Bayern 2026

Simulation only. Robots, devices, scanner events and deliveries are simulated, and all ward data is fictional. Nothing here is clinical evidence, and the security results have not yet been independently measured by the team.

  • 3D fleet consoleDispatch a delivery, run a security alert, isolate and restore a robot. Works offline in a WebGL browser.
  • Case replayShared-lift and parcel-custody walkthrough for the A01 and U02 cases. Loads some scripts from the internet.
  • Clinic World 3D model (GLB)Download the model for another 3D tool (1.5 MB).
The console, controller and replay were generated with an AI coding assistant and imported into this project; their results are unverified. Source code, scenarios and licenses: GitHub repository (see NOTICE.md). Third-party: Three.js (MIT) and Open-RMF clinic map (Apache-2.0).
